      智能体

      模板里能用的变量

      {{prompt}} 聊天记录 + 发言要求（整段文字）· {{system}} 系统提示词 · {{input}} 两者合成一段 · {{messages}} OpenAI 格式的消息数组 · {{message}} 最新一条用户消息（分工协作时是它的子任务）· {{history}} 聊天记录数组 · {{model}} 模型名 · {{max_tokens}} {{temperature}} {{stop}} 高级设置里的值 · {{key}} API Key（写在请求头里用）· {{agent}} {{persona}} 名字和人设。
      整个值只写一个变量时保留原类型（数组、数字），值为空时整个字段省略。

      轮到它发言时运行一次这条命令：提示词从标准输入传进去，标准输出就是回复（边输出边显示）；出错时显示标准错误的最后几行。提示词不会拼进命令行。模型名会放进环境变量 AGENT_HUB_MODEL。

      宽权限：能联网、运行任何命令，能写这些文件夹和工作目录。Agent Hub 自己的文件、start.command、~/Library、~/Applications、shell 启动脚本和各 AI 的配置（~/.claude、~/.codex 等）不能改；Key、SSH、登录凭证、钥匙串、浏览器数据读不到；命令都在系统沙箱里跑。其他文件读得到，联网时可能被发出去。只能在 Mac 上打开，手机发的消息也会触发它。

      接口地址和 Key 留空 = 用你在 Claude Code 里登录的账号，消耗同一个账号的额度；填 DeepSeek 的 https://api.deepseek.com 和 Key，就是让 DeepSeek 用 Claude Code 的工具干活（按 DeepSeek 的价格计费，没有网页搜索）。无论哪种权限都不能控制电脑，文件操作只限工作目录。「可用 Skill」在「可改文件」的基础上，能用你装进 Claude Code 的 skill（~/.claude/skills），能搜索、读网页；命令只能运行 agent-reach 的只读查询（搜索、读帖、取字幕），其他几档不能运行任何命令。「可用 Skill」只能在 Mac 上打开。

      用你在 Codex 里登录的 ChatGPT 账号，消耗同一个账号的额度。「只聊天」不运行命令，读不了文件。「只读」「可改文件」能运行命令，由 Codex 的沙箱限制：不能联网，「可改文件」只能写工作目录；但能读到这台 Mac 上的其他文件，所以这两档只能在 Mac 上打开。

      轮到它发言时，聊天里会出现「复制提示词」和「粘贴回复」：复制给它，再把它的回复粘贴回来。

      可选：让它自动回复
